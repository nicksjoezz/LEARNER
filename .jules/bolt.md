## 2025-03-05 - [Event Loop Blocking and Vectorized Backtesting]
**Learning:** In WebSocket-based trading bots, synchronous CPU-bound operations (like indicator calculations on large dataframes) can block the `asyncio` event loop. This causes the heartbeat mechanism to fail, leading to disconnections by the broker (Deriv API). Offloading these tasks to `asyncio.to_thread` is critical for stability. Additionally, iterative loops over large Pandas DataFrames using `.iloc` or `.iterrows` are extremely slow; vectorizing these operations with NumPy indexing can provide a 1000x speedup, making backtesting practically instantaneous even for 100k+ rows.
**Action:** Always wrap heavy data processing and ML filtering in `asyncio.to_thread` when used within an async event loop. Prioritize NumPy vectorization over Pandas row-by-row iteration for all performance-critical paths.
